# 2 : Prise en main de GitHub et environnement de travail

**Séance :** En créneau • **Durée :** 3 h 00 min

## Fait

Au début de la séance, nous avons fait la queue pour récupérer le dépôt GitHub attribué à notre groupe. Notre enseignant, Adrien BRACQ, nous a ensuite expliqué le fonctionnement global et la gestion du projet sur la plateforme. De mon côté, j'ai installé l'environnement de développement Visual Studio Code, pris en main le dépôt GitHub et commencé l'organisation de l'espace de travail en préparant le dossier et la page de chaque membre de l'équipe. En parallèle, nous avons poursuivi nos recherches sur le projet.

## Pourquoi

Il était indispensable de configurer l'outil de versionnement (GitHub) et l'éditeur de code (VS Code) pour permettre une collaboration fluide, un suivi clair de l'avancement du projet et la mise en place du journal de bord de l'équipe.
