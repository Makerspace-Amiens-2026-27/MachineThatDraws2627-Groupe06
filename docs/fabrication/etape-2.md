# Étape 2 : assemblage

{: .a_modifier }
> Page d'exemple : dupliquez-la pour chaque étape, renommez-la et changez `nav_order`.

## Procédure

1. **Organiser** tous les composants préparés à l'[étape 1](etape-1.md).
2. **Assembler** les pièces principales.
3. **Fixer** l'ensemble avec les vis M3.

## Vérifications

- Les pièces sont correctement alignées.
- L'assemblage est stable.

## Problèmes fréquents

| Problème | Solution |
|---|---|
| Les pièces ne s'emboîtent pas | Vérifier la compensation de l'imprimante (trous trop petits) |
