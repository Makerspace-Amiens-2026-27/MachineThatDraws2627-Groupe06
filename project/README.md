# Fichiers du projet

> [!IMPORTANT]
> **À modifier** : complétez ce README avec ce que contient réellement votre projet.

Ce dossier contient toutes les **sources** du projet. Ce qui s'affiche sur le site
(images, modèle 3D `.glb`, copie des fichiers KiCad) va dans `docs/assets/`.

| Dossier | Contenu |
|---|---|
| [`mcad/`](mcad/) | Conception mécanique : exports STEP, fichiers d'impression 3D et de découpe laser |
| [`ecad/`](ecad/) | Conception électronique : projets KiCad |
| [`firmware/`](firmware/) | Code embarqué (Arduino, ESP32…) |
| [`software/`](software/) | Application sur ordinateur, téléphone ou web |

Supprimez les dossiers qui ne concernent pas votre projet.

**Noms de fichiers :** pas d'espaces ni d'accents (`support-moteur.step`, pas
`Support Moteur.step`), ils cassent les liens du site.
