# Conception électronique

> [!IMPORTANT]
> **À modifier** : décrivez les cartes de votre projet.

Un dossier par projet KiCad (par exemple `carte-principale/`), contenant au minimum
les fichiers `.kicad_pro`, `.kicad_sch` et `.kicad_pcb`.

| Carte | Dossier | Rôle |
|---|---|---|
| Carte principale | `carte-principale/` | Microcontrôleur, alimentation, connecteurs |

Pour afficher une carte sur le site, copiez ses fichiers `.kicad_sch` et `.kicad_pcb`
dans `docs/assets/kicad/`, et recopiez-les quand la carte évolue.
